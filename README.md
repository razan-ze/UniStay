# 🏠 UniStay – Student Accommodation Management Platform

**UniStay** is a web-based student accommodation platform designed to simplify the process of finding and managing university housing.

Developed by **Razan Zaidan and [Hiba Ataya](https://www.linkedin.com/in/hiba-ataya-279617354/)**, UniStay connects students searching for accommodation with property owners looking to manage and publish their dormitory listings.

The platform provides a user-friendly experience for students and a dedicated management dashboard for property owners.

## ✨ Key Features

### 🎓 Student Portal

- **Browse Dormitories:** Explore available student accommodation listings.
- **Search & Filter:** Find dormitories based on university and city.
- **Dormitory Details:** View detailed information about available accommodation.
- **Favorites:** Save and manage favorite dormitory listings.
- **Responsive Interface:** Access the platform across different screen sizes and devices.

### 🏢 Property Owner Dashboard

- **Listing Management:** Create and publish new dormitory listings.
- **Edit Listings:** Update existing property information.
- **Availability Management:** Track and manage dormitory availability.
- **Dashboard:** Manage accommodation listings through a dedicated interface.

| Railway | Database hosting |

## 🏗️ System Architecture

UniStay follows a **client-server architecture**, connecting the React frontend to a Node.js backend through REST APIs.

- **Frontend:** React.js and Bootstrap provide the user interface and interactive experience.
- **Backend:** Node.js handles application logic, user requests, and API endpoints.
- **Database:** MySQL stores and manages relational data, including users, dormitories, and favorites.
- **Deployment:** The application and database are hosted using Render and Railway.
